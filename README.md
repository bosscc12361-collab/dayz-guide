# DayZ Guide by STROM

Шпаргалка по DayZ для новичков (PWA). Данные актуальны для DayZ 1.30, PC, ванильная игра.

## Как добавить или исправить карточку

Весь контент лежит в папке `data/`, по одному файлу на раздел:

| Файл | Раздел |
|---|---|
| `first15.json` | Первые 15 минут |
| `food.json` | Еда и вода |
| `diseases.json` | Болезни |
| `injuries.json` | Ранения |
| `crafting.json` | Крафт |
| `fire.json` | Огонь и температура |
| `infected.json` | Заражённые |
| `weapons.json` | Оружие и патроны |
| `slang.json` | Сленг |
| `meta.json` | Версия игры, соцсети, список разделов |

Каждый файл — это список карточек в квадратных скобках `[ ... ]`. Карточки разделены запятыми.
Самый простой способ добавить новую: скопировать похожую карточку целиком (от `{` до `}`), вставить после неё через запятую и поменять текст.

Общие поля:
- `id` — латиницей, без пробелов, уникальный. Из него получается ссылка: `#diseases/cholera`.
- `title` / `title_en` — русское и английское название.
- `tags` — слова для поиска.
- `beginner` — `true`, если «полезно новичку».
- `needs_check` — `true`, если факт нужно перепроверить. `check_note` — что именно.
- `summary` — одна строка под названием.
- `text` — подробности. Можно писать `**жирный**`, а строки, начинающиеся с `- `, превращаются в список.

Поля конкретного раздела (`symptoms`, `caliber` и т.д.) перечислены в `meta.json` у каждого раздела.

**Проверь JSON**, прежде чем выкладывать: вставь содержимое файла на jsonlint.com. Частые ошибки: лишняя запятая после последней карточки или пропущенная кавычка.

После правок код трогать не нужно. Если меняешь html/css/js, увеличь `VERSION` в `sw.js` (например, `v3` → `v4`), чтобы телефоны подхватили обновление.

## Соцсети

Ссылки на соцсети лежат в `data/meta.json` → `socials`.

## Картинки

Положи картинку в папку `img/` (лучше JPG до ~200 КБ) и допиши в карточку:

```json
"image": "img/rags.jpg",
```

или с подписью:

```json
"image": { "src": "img/rags.jpg", "caption": "Скриншот: STROM" },
```

## Ссылка на вики

Поле `"wiki": "https://dayz.wiki.gg/wiki/Rags"` добавляет в карточку кнопку «Открыть в DayZ Wiki».
